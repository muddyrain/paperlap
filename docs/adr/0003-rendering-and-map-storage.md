# 复用平面模拟，以 Three.js 和独立 V4 接入大地图

日期：2026-11-17。

本版需要真实 3D 追车视角和超出一屏的路线，同时保持旧作品尺寸与已有成绩。直接放大旧 `WORLD` 会改变旧路线验证边界；只把旧俯视画面倾斜也不能提供车后方看路的空间感。

驾驶画面由 Three.js 渲染。Phaser 保留唯一更新循环，沿用 120 Hz 固定步长、平面车辆模型和有效圈规则；`RaceView` 只读取车辆与路线，不修改模拟。道路通过中心线生成网格，纸张使用 256×256 重复纹理；装饰实例化，地图扩大不会生成同等面积的大位图。镜头位于车后上方，随帧间隔平滑跟随，暂停不推进镜头，重置立即回到起点视角。

俯视编辑使用固定分辨率画布与独立视口变换。缩放和平移不写入道路坐标或撤销历史。新 Track schema 2 使用 5760×3440 地图；旧 schema 1 保留 1440×860 边界。完整路线仍受道路校验和 900 点上限约束。

正式数据写入独立 `paperlap.save.v4`，分段草稿写入 `paperlap.draft.v3`，新版局部草稿写入 `paperlap.local-draft.v2`。V3/V4 共享验证与事务核心，同时保留原 V3 入口的兼容合同。旧正式键保留原文字节，V3 升级保留作品 UID、几何身份、摘要和 PB；来源摘要和共用 Web Lock 阻止新旧客户端并发改写。

修改渲染方式不改变驾驶规则版本，仍使用版本 2。只有修改路线才创建新的几何身份。场景资源在正式写盘前准备；失败时释放候选，成功后提交。WebGL2 初始化或上下文丢失时显示恢复入口，避免让失去画面的赛车继续计时。

代价是同时发布 Phaser 与 Three.js，生产主脚本约 1.93 MB（gzip 约 517 KB）。像素比上限为 1.25，静止画面跳过重复 GPU 绘制；具体帧耗时与资源变化见[验证记录](../next-version-verification.md)。
