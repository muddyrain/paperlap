# 下一版采用追车视角，赛道保持平面

用户认为固定全图俯视和一屏内画线限制了赛道长度与驾驶趣味，已选择车后上方跟随的 3D 驾驶视角、平面道路，以及一条无法一屏看完的较长样例赛道，初步以实际驾驶一圈 30–60 秒为目标。下一版据此验证驾驶体验，先不引入坡道、腾空与落地规则，使现有平面路线、车辆运动与计圈逻辑仍有复用基础；这项范围选择不决定具体渲染技术或大地图的绘图交互。

该决定适用于下一版，产品主线仍是驾驶进步，优先供用户自己与少量朋友试玩。它更新了首版固定俯视的范围，尚不表示功能已经实现；当前实现仍以 `README.md` 和代码为准。

Q9 A 进一步确认：驾驶统一使用 3D 追车视角，俯视用于绘图和查看全图，本版不提供驾驶中的 2D/3D 切换。30–60 秒是样例赛道的试玩目标，不是自绘赛道的圈时或长度上限。
