# 大地图采用平移缩放与分段续画

用户选择在可平移、缩放的较大纸面上逐段画赛道：画一段后松手，移动画布，再从末端继续，最后接回起点闭合。这取代首版要求整条路线在同一屏内一笔完成的绘制方式，解决长赛道受屏幕范围限制的问题，并允许玩家停下来规划后续弯道。

相较一笔绘制配合边缘自动滚动或总览画完后再展开，分段续画需要把未闭合路线作为可继续的创作状态，明确绘制段和续画位置；它不意味着支持道路分叉或开放赛道比赛。

Q8 A 进一步确认：未闭合时按绘制段撤销重画，闭合后使用局部调整，不增加未闭合时任意拖动旧段的交互。局部调整沿用当前正式作品入口，即路线闭合、通过校验并保存后再修改；闭合失败时保留分段草稿供撤销重画。
