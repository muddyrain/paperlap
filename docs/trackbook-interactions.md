# P1-03：快捷键、焦点和赛道本交互

基线：master / `24dd2c1`，对应 [Issue #5](https://github.com/muddyrain/paperlap/issues/5)。先确定操作规则，再实现抽屉、卡片与动效。Save V2 及控制层提交顺序不变。

| 范围                                     | 按键            | 行为                                                                        |
| ---------------------------------------- | --------------- | --------------------------------------------------------------------------- |
| 获得焦点的游戏区域，ready/running/paused | T / E           | 打开赛道本 / 编辑当前赛道；进入任一界面先暂停、释放驾驶键                   |
| 同上                                     | Space           | ready 开始、running 暂停、paused 继续                                       |
| 同上                                     | R               | 与“重新开始”按钮一致：回起点并开始新一圈；三个游戏状态均可用                |
| 同上，running                            | Esc             | 暂停；ready/paused 不执行危险操作                                           |
| 抽屉列表                                 | N               | 新建独立赛道；达到 20 条时保留列表并说明上限                                |
| 抽屉卡片主按钮                           | ↑ / ↓           | 在赛道主按钮之间循环移动焦点，不选择、不驾驶                                |
| 抽屉卡片主按钮                           | Enter / Space   | 原生按钮激活：使用赛道，保存成功后 ready，不自动起跑                        |
| 抽屉                                     | Esc             | 改名/删除确认先回列表，列表关闭抽屉；关闭后回到原入口或游戏区域，不自动恢复 |
| 绘图                                     | R / Enter / Esc | 重画 / 保存 / 取消；新建保存后 ready，编辑保存后 running                    |

首次加载、取消绘图和点击暂停后焦点进入游戏区域，Tab 可到达可用按钮。游戏快捷键只从游戏区域触发；按钮上的 Enter/Space 保留原生点击。绘图按钮上的 Enter 保留原生动作，R/Esc 保留绘图操作。输入框、contenteditable、IME、Ctrl/Meta/Alt 组合不触发动作；输入框中的普通 Esc 仅退回列表。动作快捷键忽略长按重复，列表上下移动允许重复；抽屉按钮原生 Enter 的首次激活保留，重复激活会阻止，以免改名后的焦点转移意外切换非当前卡片。所有键盘动作在 board/dialog 内协调，不增加 window 抢键。

只给以上真实动作显示键帽，并同时显示图标、中文文本及 aria-keyshortcuts。改名/删除不增加 F2/Delete；通过 Tab 和原生按钮操作，删除必须确认。确认按钮不标一个会越过取消焦点的 Enter 快捷键。子页面的顶部关闭按钮改为“返回列表”，与 Esc 层级一致。

右侧抽屉使用原生 dialog，Tab/Shift+Tab 在可见按钮与输入框的首尾循环，覆盖场景但不改变 Phaser 画布尺寸与世界坐标。打开时聚焦活动卡片；改名取消/成功回原卡片，删除后回剩余活动卡片，切换后留在目标卡片。20 条列表内部滚动。卡片显示真实中心线/道路宽度缩略图、名称、当前规则最佳及活动标记；缩略图仅在界面渲染时生成，不在每帧生成，也不进入存档。

抽屉约 220ms 滑入、200ms 滑出，关闭期间继续保持 dialog 语义；新的列表操作可中止退出，快速重开不会被旧动画回调关闭。减少动态效果时立即打开/关闭。卡片悬停与按钮按压只改变 transform；切换反馈只发生在控制层保存、场景提交成功之后，重选和失败不触发成功动画。改名/删除反馈留在抽屉，游戏保存/纪录反馈留在边缘，不遮挡道路。

存储失败保留旧卡片、活动 UID、纪录及场景；错误可见，焦点留在当前操作。新建失败保留有效绘图，取消不写盘。场景异常沿用 P1-02 的停止渲染与重载恢复。动画不参与持久化，不改变物理、模拟时间或圈速。
