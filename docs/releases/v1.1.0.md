# Paperlap v1.1.0：3D 追车与大地图

本版把驾驶画面改为真实 3D 追车视角，并允许在超出一屏的大纸面上分段画赛道。正式站点：[paperlap.vercel.app](https://paperlap.vercel.app)。

- 3D 玩具赛车、道路与环境；驾驶保留原有平面运动和计圈规则。
- 新增长样例“长纸环游”，自动驾驶测试通过真实键盘跑出约 53.6 秒有效圈。新用户默认使用；老用户可从赛道本点击“体验长赛道”新增独立作品。
- 大地图支持平移、缩放、从末端续画、按段撤销/重做、闭合保存及刷新恢复草稿。保存成功后等待玩家主动开始。
- 保存后的长赛道可进入俯视局部调整，拖动弯道、采用和保存；新路线与旧路线成绩分开。
- 独立 Save V4 保留旧作品尺寸、身份和 PB，V1/V2/V3 原始键保留。旧整笔草稿保留原文，不自动套入新分段草稿。

核心测试 143 项通过；无头浏览器验证长样例有效圈、自绘 12 段跨屏路线、刷新恢复、局部改弯、成绩隔离、三种桌面尺寸和重复编辑资源释放。详见[验证记录](../next-version-verification.md)及[存档兼容说明](../save-v4.md)。

需要支持 WebGL 2 的桌面浏览器，键盘驾驶优先。生产包同时包含 Phaser 和 Three.js；实测无头浏览器性能不代表所有设备帧率。玩法规则版本仍为 2。

用户已试玩并授权先发布现有版本。下一阶段玩法尚未定稿，幽灵、奖牌、道具、AI 对手和机关不在此版本中。
