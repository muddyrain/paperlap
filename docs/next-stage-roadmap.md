# 下一阶段建议：让驾驶进步看得见

日期：2026-11-17。状态：原建议未采纳，后续迭代暂缓。本文仅保留讨论记录，不作为下一轮实施范围。

用户认为以下建议对新增功能和趣味性的改善不足。随后讨论了漂移与氮气、AI 对手竞速、可摆机关的赛道，但尚未选择方向。用户最终决定先提交发布现有版本，之后再讨论迭代。

3D 追车与大地图分段绘制已经实现。用户试玩反馈为“还行”，并要求列出下一步。沿用此前确认的定位：PC 单人驾驶进步，优先供自己和少量朋友玩。

## 原建议（未采纳）

围绕“跑一圈 → 看见哪里变快 → 再试一圈”完成一个增量。

| 顺序 | 功能 | 玩家能得到什么 |
| --- | --- | --- |
| 1 | 个人最佳幽灵车 | 与自己的最佳有效圈同场驾驶，直观看见线路、刹车点和距离差；提供显示开关，不产生碰撞 |
| 2 | 分段快慢对比 | 经过少量明确的分段点时，短暂显示相对最佳圈快或慢了多少，帮助定位需要练习的路段 |
| 3 | 圈后简短反馈 | 显示本圈、个人最佳、提升或落后时间，并提供明确的重试入口；自由连续驾驶仍可继续 |

幽灵与分段参考必须属于同一作品、几何修订和驾驶规则。旧 PB 没有轨迹，继续保留成绩，并明确显示参考轨迹尚未建立；不伪造旧纪录的幽灵。新记录需要明确站立起跑与连续飞驰圈的比较方式，设计与实现时保持幽灵播放和差值使用相同基准。

完成判据：跑出真实有效圈后能保存并刷新恢复对应参考；下一圈幽灵、分段差与计时同步；暂停、重新开始、失焦恢复不发生错位；改线后不套用旧路线轨迹；保存失败不让 PB 与轨迹错误配对。驾驶中的提示短暂且不遮挡前方道路。

## 原候选顺序（未确认）

| 顺序 | 功能 | 建议首批范围 |
| --- | --- | --- |
| 4 | 挑战赛道册与奖牌 | 三条有明确差异的路线：高速流畅、连续弯、刹车与发夹弯；铜银金目标通过实际试玩标定，保存本地进度 |
| 5 | 赛道分享 | 单赛道文件导出、导入预览和保存，让朋友使用同一路线；不把完整个人存档备份当作分享文件 |
| 6 | 驾驶表现与操作打磨 | 根据试玩具体问题调整看弯距离、转向反馈与路面辨识；若改变运动规则，应保留旧纪录并使用新的规则版本 |

挑战目标绑定固定路线和挑战版本；玩家改线后作为自由作品驾驶。分享先验证路线交换流程，再考虑共享成绩或好友异步挑战。

车辆养成、特殊路面、坡道跳跃和实时多人仍留在候选池，暂无实施顺序。以上顺序是基于当前产品目标的设计建议，不代表已有留存或玩家对比测试支持。
