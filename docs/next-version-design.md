# Paperlap 下一版：画长赛道，用 3D 追车视角驾驶

日期：2026-11-17。状态：已实现，用户已试玩并反馈“还行”，决定先提交发布。用户已确认 Q1–Q9 的方向选择，并在整体核对后确认按本文范围定稿；本文保留范围与验收基线。实现与自动化证据见[本版验证记录](next-version-verification.md)，后续玩法暂缓，具体镜头与驾驶体验可继续收集试玩反馈。

## 目标

让用户和少量朋友能画出超出一屏的闭合赛道，并用有前进纵深的追车视角练习驾驶、刷新自己的成绩。当前用户明确感到固定全图俯视下赛道太小、驾驶无趣；本版优先验证更长路线与新视角是否改善体验。

核心循环：**俯视分段绘制 → 闭合校验并保存 → 3D 追车试跑 → 俯视局部改弯 → 再次试跑。**

## 已确认的范围

| 决策 | 下一版行为 |
| --- | --- |
| 主体验与受众 | 驾驶进步，优先供用户自己和少量朋友玩 |
| 规划单位 | 完成一个可玩的核心增量及其验收 |
| 驾驶视角 | 从车后上方随车移动，朝前看路；镜头适当抬高以看清弯道 |
| 道路与表现 | 道路保持平面；车辆、环境和镜头采用 3D 表现，延续方格纸与玩具赛车主题 |
| 样例内容 | 一条更长的赛道，包含直道、需要减速的弯和连续弯；实际驾驶一圈暂以 30–60 秒为目标 |
| 自绘方式 | 俯视纸面可平移缩放，从路线末端分段续画，最后接回起点闭合 |
| 修改方式 | 未闭合时按段撤销重画；闭合、校验通过并保存后使用局部调整 |
| 视角分工 | 3D 用于驾驶，俯视用于绘图与查看全图 |

30–60 秒仅用于标定样例赛道，不作为自绘赛道的长度或圈时限制。地图范围不随窗口大小变化；编辑缩放只改变观察范围，不缩放已经画好的路线、道路宽度或车辆。

## 玩家流程

1. 打开游戏可直接在长样例赛道开始驾驶；沿用键盘油门、刹车、转向、暂停和重新开始。
2. 新建作品进入俯视编辑，先画一段直道或弯道，松手保留这一段。
3. 移动画布或缩放，找到末端继续绘制。已画路线保持原位置与尺度；可以查看全图确认布局。
4. 按绘制段撤销或重做。画错当前段时显示问题预览和原因，可重画该段，前面已完成的路线保留。
5. 接回起点时显示闭合提示，并对完整路线校验；合法后保存为作品，进入等待开始状态。
6. 开始后使用 3D 追车镜头驾驶。地图不必全在屏幕内，HUD 不再决定道路的世界边界。
7. 完成有效圈并查看个人最佳；想改弯时暂停进入俯视局部调整，保存后重新试跑。

## 草稿与失败恢复

以下行为是已有安全行为在分段续画中的延伸，已随整体方案确认：

- 未闭合是可继续的草稿状态，不当作绘图错误，也不当作正式可驾驶赛道。
- 已完成的绘制段和续画位置需要备份；刷新并恢复后可从末端继续。恢复整个撤销栈不是本版额外承诺。
- 拖画中失焦、缩放窗口或丢失指针时结束当前手势，已完成段保留；恢复后由玩家重新落笔。
- 不合法的段或闭合结果保留可见提示；正式保存前必须完整校验。闭合失败仍使用分段草稿，允许逐段撤销重画，不暗中加入任意旧段编辑。
- 保存失败不覆盖旧正式作品，不清理尚未成功保存的草稿，不显示保存成功。
- 平移和缩放只操作编辑视图，不占用道路的撤销历史。

## 既有作品与成绩

合法旧作品应能加载并用新的驾驶视角试玩，保持原路线尺寸与名称；不为了匹配长地图而自动放大旧路线。旧存档原文与历史成绩应按现有保留原则处理。

本版先沿用平面驾驶和有效圈规则。仅更换镜头与显示方式，不构成清空个人最佳的理由；若实施中确实改变车辆运动或计圈规则，则必须区分规则版本并保留旧成绩。修改路线继续区分几何修订。

数据兼容、写入协议与容量上限在实施设计中明确，不能依靠单独放宽 `WORLD` 或旧客户端的校验阈值来宣称兼容完成。

## 验收标准

### 绘制与驾驶贯通

- 通过真实指针画至少三段，中间移动画布并改变缩放；接缝连续，缩放前后同一位置仍对应同一路线。
- 完成一条超出初始编辑视图的路线，闭合、保存、刷新，并能用 3D 视角跑出有效圈。
- 在尚未闭合的多段草稿上刷新，恢复后能继续；撤销、重画问题段、闭合失败和保存失败均保留应保留的作品及草稿。
- 闭合保存后能进入局部调整，修改一个弯，保存并重新驾驶；新几何不错误继承旧 PB。

### 驾驶体验

- 样例赛道包含直道、减速弯和连续弯，以实际键盘驾驶标定到约 30–60 秒一圈，不以减慢车辆来机械凑时长。
- 追车镜头持续看得见车辆和前方道路；弯道进入视野后有可操作的减速与转向时间。暂停、重置和失焦恢复时镜头、车辆、计时状态一致。
- 保留清楚的起点与道路边界；装饰和 HUD 不遮住驾驶所需的信息。
- 用户与少量朋友实际试玩，记录看弯是否清楚、转向是否可预测、长赛道是否仍乏味，以及是否愿意主动再试一圈。“更好玩”不能仅由自动化测试宣布通过。

### 兼容与运行

- 核对合法旧作品、旧纪录和草稿的保留与归属；测试新长路线保存刷新和旧版本数据读取。
- 自动化使用隔离的无头浏览器，按 `AGENTS.md` 检查三种既有桌面尺寸、输入、计圈及保存链路，不接管用户桌面。
- 对实际 3D 驾驶与反复编辑记录帧耗时和资源变化，注明硬件与浏览器；地图扩大不应通过无限扩大全世界位图实现。具体性能预算在实施基线测量后确定。

## 本版边界与实施顺序

坡道、跳跃、立交、道路分叉、未闭合时任意编辑旧段、驾驶中切换 2D/3D，不进入本版。挑战册、奖牌、幽灵、好友分享、车辆养成保留为后续候选。

建议实施时先用长样例验证 3D 追车与平面驾驶，再接通大纸面的分段绘制，最后完成局部调整、草稿与旧存档兼容以及贯通验收。具体渲染技术和数据协议由实施审查确定，本轮不预先锁定库或给出工期承诺。

实施结果：使用 Three.js 绘制 3D 场景，Phaser 继续调度原有平面驾驶与计圈；编辑地图为独立的 5760×3440 世界，旧作品保留 1440×860 尺度。新存档使用独立 V4，详见[技术决策](adr/0003-rendering-and-map-storage.md)与[存档协议](save-v4.md)。
