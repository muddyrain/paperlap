# P1-04A：Esc 游戏菜单与覆盖层状态

基线 master `ac678a6`，实现 [Issue #7](https://github.com/muddyrain/paperlap/issues/7)。本轮只有静态纸片菜单及可靠状态/焦点，完整动效留给 #8。

P1-05A 补充：R 清空后只要仍有可撤销笔迹，就仍算有草稿，Esc 必须确认放弃。已确认备份的放弃须先可靠清理，失败留在编辑；初始备份无法确认时，确认页可“仅放弃本次绘制”并返回，不删除任何未知旧备份；“暂不处理”保留备份并沿原入口返回。下表“不写盘”均指正式 Save V2；独立恢复弹窗和备份生命周期见 [草稿安全](draft-safety.md)。

赛车仍使用 ready / running / paused / editing；独立 MenuState 管理 none / menu / controls / trackbook / discard，不改变模拟时间和存档语义。

| 来源 / 当前层                      | 动作               | 结果                                                                                                   |
| ---------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------ |
| ready / paused，游戏区域或普通按钮 | Esc / 顶部菜单     | 打开首页，保留 ready/paused；不建立恢复许可                                                            |
| running，游戏区域                  | Esc / 顶部暂停     | 记录赛道身份与恢复许可，再暂停、清驾驶键、关闭引擎，显示首页                                           |
| menu                               | Esc / 关闭         | 仅有有效恢复许可、仍是同赛道 paused、文档和菜单焦点均正常时恢复 running；否则仅关闭并保持 ready/paused |
| menu                               | Space / 继续或开始 | 显式关闭并开始/继续，焦点回 #game，不继承旧 held keys                                                  |
| menu                               | R / 重新开始       | 沿用重置并开始，持久化最佳保留                                                                         |
| menu                               | T / 我的赛道本     | 撤销恢复许可，先关菜单再开抽屉；抽屉结束返回首页                                                       |
| 游戏区域                           | T                  | 直接开抽屉；关闭回原游戏入口，不自动恢复                                                               |
| 抽屉改名 / 删除确认                | Esc                | 先返回列表，再退出抽屉；保留现有写入/失败恢复                                                          |
| menu                               | E / 编辑当前       | 撤销许可，进入 replace；取消回菜单                                                                     |
| 抽屉                               | N / 新建           | 进入 create；取消回来源抽屉；保存后 ready，离开菜单流程                                                |
| menu                               | 操作说明           | 进入说明；Esc / 返回按钮只回首页                                                                       |
| editing，无笔迹                    | Esc / 取消编辑     | 直接还原旧场景，不写盘，返回编辑入口                                                                   |
| editing，有笔迹 / 预览             | Esc / 取消编辑     | 中断正在捕获的笔划但保留内容，打开放弃确认；默认聚焦继续绘制                                           |
| discard                            | Esc / 继续绘制     | 关确认、回绘图，保留草稿及有效预览                                                                     |
| discard                            | 显式放弃修改       | 还原旧车位、计时、赛道，不写盘，回编辑入口                                                             |
| 编辑保存成功                       | Enter / 保存按钮   | 沿用 create→ready、replace→running；清空返回链                                                         |
| blur / hidden / resize             | 生命周期           | 撤销自动恢复许可；blur/hidden 继续暂停、清键与静音，不因恢复焦点自动起跑                               |
| recovery / reloadRequired          | 任意入口 / 快捷键  | 清覆盖层与返回链，禁止启动、重开或重新编辑坏场景；只允许重载恢复                                       |

恢复许可只属于一次菜单会话，不跨赛道本、编辑、重开、故障或窗口生命周期。遮罩点击只关闭/返回，不恢复驾驶。编辑入口记录 game、menu、book-game 或 book-menu，避免编辑取消后掉到错误页面。所有模态路由先关闭旧 dialog 再打开新 dialog，任一时刻最多一个 open dialog。

菜单首页按键：Esc 返回、Space 继续/开始、R 重开、T 赛道本、E 编辑。按钮焦点上的 Enter/Space 仍是原生点击，Space 不同时触发菜单继续；声音与说明不标虚构快捷键。操作说明和放弃确认只处理自己的 Esc。输入框、contenteditable、IME、Ctrl/Meta/Alt 不触发动作；长按动作键与原生按钮的重复 Enter 不重复提交。Tab/Shift+Tab 环绕当前可见控件。

主游戏 Space 保留快速开始/暂停/继续，不打开菜单。驾驶按键只接收首次 keydown，keyup 正常释放；暂停期间清空后，旧键的 repeat 不能重新加油，必须松开重新按。窗口/标签失焦处理始终保留。声音按钮在主游戏驾驶中的鼠标防失焦逻辑保留；菜单声音只切换声音并留在菜单，不启动游戏，写入失败在菜单明确提示。

菜单显示活动名称与冻结圈时，长名支持 title/可访问全文，内容可内部滚动；纸片位于左侧，避开默认车位/起点并保留大部分路线。P1-04A 不增加转场等待，reduced-motion 下同样可立即操作。控制层负责状态，DOM 只按状态呈现；失败不建立成功态，不改 Save V2、trackbook.ts 原子提交、物理、圈速、几何或 RULES_VERSION。

P1-04B 在上述即时状态/焦点规则上增加独立纸片视觉层，详见 [Motion Spec](game-motion.md)。退出时真实 dialog 立即关闭，仅不可交互副本短暂收走；不等待动画决定是否恢复。保留默认 DOM 焦点，鼠标路径不显示厚框，键盘使用短铅笔线和柔和底色，不绘制封闭外框；该呈现不改变恢复许可与原生按钮操作。
