## 方法与旧基线

Apple M3 Pro / macOS / Chromium 141.0.7390.37，生产构建，隔离 headless Chromium，上下文内 CDP 1×/4× CPU 降速；不接管桌面。200/450/900 点 × 1/5/20 条赛道 × 两种 CPU 共18组。每组冷启动、两轮进入/保存，每轮三次真实鼠标拖动/采用。第一份草稿是冷备份，后续是已有精确快照的热路径；冷启动外部 JSON 全量校验另列，不把热路径当作未知存档的读取速度。

`?debug=1&profile=1` 启用2000条有界只读阶段样本；正常游戏不采样。不修改状态、物理、校验决策或写入协议。阶段是包含子阶段的CPU墙钟时间，不能把嵌套时间相加。`v3.validate` 包括原几何/元数据、身份/摘要、records/archive 与序列化检查；`v3.digest` 是其子阶段，剩余时间包含记录/归档/元数据而非另一轮几何。另记录真实 Storage 读/写/读回以及900点20赛道4×的 CDP CPU profile。

## 已证实热点与优化边界

900点4×、20条赛道：首次草稿备份232.6ms，包含候选和原路线各约113ms严格检查；已有备份的后续新候选仍再检查约113ms。保存事务509.2ms，包含额外的局部检查114.1ms、V3候选166.8ms、准备52.2ms、可靠写入69.0ms、场景应用104.4ms。重叠阶段不可累加。

只复用同一次编辑来源（UID、revision、digest、算法）和全点一致的私有不可变快照证据，缓存有界；不以32位指纹或摘要命中代替精确比较。松手新几何仍完整检查；未知/恢复草稿、外部字节仍严格验证；V3最终几何、摘要、元数据/记录/历史、原文冲突、Web Locks和写后读回保留。场景纹理应用成本本轮不重写。

操作规则：校验、采用、保存先显示短状态并让浏览器绘制，再执行计算；处理中禁止新拖动、撤销和重复事务。Esc、blur/hidden、resize和来源变化取消尚未执行的任务；只保留已采用历史与可恢复草稿，不自动提交旧结果。同步可靠事务开始后遵循原顺序完成，失败回退不变。
